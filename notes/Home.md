## Open this vault

In Obsidian, select **Open folder as vault**, then choose the `notes` folder in this repository. Start with this note.

Notes and shared configuration are tracked in Git. Local workspace layout, cache, and deleted-note trash are ignored.

Keep credentials and private account information out of these notes.
